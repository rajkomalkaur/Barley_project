# GWAS of Phosphate Starvation Response in Barley

This repository contains the R script used for genome-wide association analysis of 12 phosphate starvation response traits in 26 Eastern European barley lines.

## Contents

- `gwas_analysis.R` — R script for genotype processing, PCA, and FarmCPU GWAS using GAPIT
- `all_phenotypes.csv` — Phenotypic data for all 26 lines and 36 traits

## Analysis overview

The script performs: genotype loading and filtering, PCA, and GWAS for 12 response traits using the FarmCPU model.
